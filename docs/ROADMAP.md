# Taurrent — план разработки

Кроссплатформенный BitTorrent-клиент на Tauri 2 + React.

## Стек

| Слой | Выбор |
|---|---|
| Оболочка | Tauri 2 |
| Торрент-движок | [librqbit](https://github.com/ikatson/rqbit) 9 (чистый Rust, `rust-tls`) |
| Фронтенд | React 19, TypeScript, Vite |
| UI | Tailwind CSS v4, shadcn/ui (Radix, preset Nova), lucide-react |
| Состояние | Zustand |
| Таблицы | TanStack Table + TanStack Virtual |
| Пакеты | npm |
| Платформы | Linux (AppImage / deb / rpm), Windows (MSI / NSIS) |

## Архитектура

```
React UI ──invoke()──▶ Tauri commands ──▶ Engine (librqbit Session)
   ▲                                            │
   └──────── event "torrents:update" (1 Гц) ◀───┘
```

- `src-tauri/src/engine.rs` — обёртка над `librqbit::Session`: старт, персистентность, операции над торрентами.
- `src-tauri/src/commands/` — тонкий слой Tauri-команд, ошибки сериализуются в строку.
- Фоновая задача раз в секунду собирает снапшот статистики и шлёт его во фронт одним событием (без поллинга с фронта).
- `src-tauri/src/settings.rs` — настройки приложения (JSON в `app_config_dir`, атомарная запись).
- `src/lib/api.ts` — типизированные обёртки над `invoke`, `src/store/` — Zustand-сторы.

### M1. Ядро: добавление и управление торрентами ✅

- [x] При добавлении передавать `AddTorrentOptions::output_folder` = папка из настроек (дефолт сессии librqbit задаётся только при старте). С явным `output_folder` librqbit не создаёт подпапку для многофайловых торрентов, поэтому если папка отличается от дефолта сессии, метаданные сначала получаются через `list_only` (magnet ждёт до 90 с) и подпапка вычисляется нами
- [x] Отдавать `TorrentSummary` в формате фронта (`src/lib/types.ts`): прогресс, статус, скорости, сиды/пиры, ETA, скачано/отдано. librqbit не различает сидов и личей: «Сиды» — подключённые пиры, «Пиры» — все известные. Время добавления хранится в `session/added.json`
- [x] Фоновый эмиттер статистики (`torrents:update`, 1 Гц), история скоростей (60 точек) на бэкенде
- [x] Кнопка «Добавить торрент» в сайдбаре (.torrent-файл / magnet), контекстное меню строки: пауза/запуск, удалить, удалить с файлами (с подтверждением); ошибки — тосты (sonner)
