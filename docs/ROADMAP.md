# Taurrent — план разработки

Кроссплатформенный BitTorrent-клиент на Tauri 2 + React.

## Стек

| Слой | Выбор |
|---|---|
| Оболочка | Tauri 2 |
| Торрент-движок | [librqbit](https://github.com/ikatson/rqbit) 9 (чистый Rust, `rust-tls`) |
| Фронтенд | React 19, TypeScript, Vite |
| UI | Tailwind CSS v4, shadcn/ui (Radix, preset Nova), lucide-react |
| Состояние | Zustand |
| Таблицы | TanStack Table + TanStack Virtual |
| Пакеты | npm |
| Платформы | Linux (AppImage / deb / rpm), Windows (MSI / NSIS) |

## Архитектура

```
React UI ──invoke()──▶ Tauri commands ──▶ Engine (librqbit Session)
   ▲                                            │
   └──────── event "torrents:update" (1 Гц) ◀───┘
```

- `src-tauri/src/engine.rs` — обёртка над `librqbit::Session`: старт, персистентность, операции над торрентами.
- `src-tauri/src/commands/` — тонкий слой Tauri-команд, ошибки сериализуются в строку.
- Фоновая задача раз в секунду собирает снапшот статистики и шлёт его во фронт одним событием (без поллинга с фронта).
- `src-tauri/src/settings.rs` — настройки приложения (JSON в `app_config_dir`, атомарная запись).
- `src/lib/api.ts` — типизированные обёртки над `invoke`, `src/store/` — Zustand-сторы.
